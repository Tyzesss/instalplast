# Instal-Plast

Landing page Instal-Plast (Zielona Góra) — kotły, pompy ciepła, klimatyzacja, serwis 24/7 i termowizja.

Brief personalizacji: `PERSONALIZACJA.md`.

## Development

Potrzebujesz Node.js i npm — [instalacja przez nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

```sh
npm run build
npm run preview
```
